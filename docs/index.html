快速部署你的静态站点

这是一个简单的 GitHub Pages 演示页面。将本目录放入仓库的 docs/，然后启用 Pages 即可访问本站点。

查看功能

部署简单

将文件放到 docs/，在仓库 Settings → Pages 中选择 main /docs 分支即可。

响应式设计

页面在手机/平板/桌面都能友好显示。

主题切换

右上角按钮可切换亮/暗主题，示例使用 localStorage 保持用户偏好。

关于这个 demo

这是一个纯静态示例，没有后端依赖。你可以在此基础上替换内容、添加页面或引入静态站点生成器（Jekyll、Hugo 等）。
